## Descripción del desafío

En este desafío, crearás un agente de investigación avanzado que pueda buscar información en internet, procesar los resultados y mantener memoria de las investigaciones realizadas. Este agente será capaz de responder preguntas sobre diversos temas, recordar información de conversaciones anteriores y proporcionar respuestas contextualizadas y actualizadas.

Este proyecto te permitirá aplicar los conceptos de agentes, herramientas y memoria persistente que hemos explorado en este episodio, creando un asistente de investigación verdaderamente útil.

## Objetivos

Tu agente de investigación debe cumplir con los siguientes requisitos:

1. **Capacidades de búsqueda**:
   - Utilizar SerpAPI para buscar información actualizada en internet
   - Analizar y sintetizar los resultados de búsqueda

2. **Memoria persistente**:
   - Implementar un sistema de memoria que persista entre sesiones
   - Almacenar información relevante de investigaciones previas
   - Recuperar y utilizar esta información cuando sea pertinente


## Recursos necesarios

### API Keys y servicios

Para este desafío, necesitarás:

1. **SerpAPI**:
   - Regístrate en [SerpAPI](https://serpapi.com/) para obtener una API key
   - La capa gratuita incluye 100 búsquedas mensuales, suficientes para este desafío

2. **Modelo de lenguaje**:
   - Puedes utilizar Google AI (Gemini), OpenAI, Anthropic o cualquier otro proveedor compatible
   - Asegúrate de tener una API key válida


## Conceptos clave

- **Agentes de investigación**: Cómo diseñar agentes especializados en búsqueda y análisis de información.
- **Memoria persistente**: Técnicas para almacenar y recuperar información a largo plazo.
- **Integración con APIs de búsqueda**: Cómo conectar agentes con servicios de búsqueda web.
- **Síntesis de información**: Estrategias para combinar y presentar datos de múltiples fuentes.
