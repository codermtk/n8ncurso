# Curso de n8n para Inno 8n

Bienvenido al curso de n8n para Inno 8n. Este curso está diseñado para ayudarte a dominar n8n, una poderosa herramienta de automatización de flujos de trabajo sin código.

## Acerca de este curso

En este curso, aprenderás desde cómo instalar n8n hasta cómo crear flujos de trabajo complejos con inteligencia artificial. Cada episodio incluye desafíos prácticos para reforzar tu aprendizaje.

## Estructura del curso

El curso está organizado en episodios, cada uno centrado en un aspecto específico de n8n:

- **Episodio 2**: Cómo instalar n8n
- **Episodio 3**: Introducción a la interfaz de usuario de n8n
- **Episodio 4**: Conceptos Fundamentales y Fundamentos de Construcción n8n
- **Episodio 5**: Profundizando en los Triggers
- **Episodio 6**: Profundizando en nodos de Data
- **Episodio 7**: Nodos de Lógica (Flow)
- **Episodio 8**: Nodos Core
- **Episodio 9**: Juntando todo a la vez
- **Episodio 10**: Nodos de IA 1: Intro y Chains
- **Episodio 11**: Nodos de IA 2: Agentes, Intro Memoria, Intro Herramientas
- **Episodio 12**: Nodos de IA 3: RAG y Vector Stores
- **Episodio 13**: Nodos In App

Selecciona un episodio del menú lateral para comenzar con los desafíos.

## ¿Qué es n8n?

n8n es una herramienta de automatización de flujos de trabajo que te permite conectar diferentes servicios y aplicaciones. Con su interfaz visual, puedes crear flujos de trabajo complejos sin necesidad de escribir código.
